# 後台設計參考

## HQ 任務精靈參考

檔案：`hq-task-wizard-reference-2026-08-31.png`

採用的重點：

- 清楚顯示總步驟與目前步驟
- 一個畫面只做一個決定
- 先搜尋既有資料
- 大型搜尋結果與選擇區
- 固定的上一步／下一步導覽
- 下一步不可用時直接停用

## HQ 黑白任務台母版

檔案：`hq-monochrome-task-canvas-2026-08-31.png`

補充參考：[ChatGPT 分享頁](https://chatgpt.com/share/6a953b61-4eb0-83ed-a816-e3250ead0975)

若外部分享連結失效，以儲存庫內的參考圖與 `docs/FURMOSA-HQ-UX-SYSTEM.md` 為共同依據。

採用的重點：

- 暖白背景、白色主工作區與黑灰文字
- 粗黑外框、大圓角、單一硬邊位移陰影
- 大面積留白與明確字級層級
- 橫向步驟圓點與細連接線
- 單一大搜尋框與平面結果列
- 一個實心主要按鈕、清楚的停用狀態
- 簡單線性圖示，不靠多色狀態標籤

不直接複製的部分：

- 參考圖的客戶、店家混合結果不套用到合作店家流程
- 不把所有清單與詳細頁硬做成四步驟
- 不為了遊戲感加入徽章、彩帶或大量裝飾
- 不讓視覺參考覆蓋 MER、合作功能、權限、金流與資料安全規則
