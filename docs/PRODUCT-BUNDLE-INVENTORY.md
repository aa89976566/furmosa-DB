# 按單分裝組合

每個 ProductPriceTier 可設定 ProductBundleComponent，指定單品與每包克數。三種單品各15g的家有三寶45g，成本99元、售價275元。

- 接單／叫貨申請不扣原料；正式出貨（含無出貨單的已完成訂單）沿用既有 hq_bulk_post 交易。
- 每包各扣15g；不扣零庫存成品、不建立虛構成品庫存。POS 店家收到後仍以包管理。
- 帳冊保存配方快照，重送不重扣；取消／退貨按原帳冊回補，配方修改不影響歷史。
- 克數須正整數、配方總重須符合規格；來源須為克數管理的 STANDARD 單品，禁止巢狀組合。原料可以是未獨立販售的 draft。
- 沿用 HQ 原有負庫存提醒政策，不改 POS 禁止負庫存規則。
- ProductBundleComponent 啟用 RLS，anon/authenticated 無權；僅既有伺服器 DB role 可使用。

本次 migration 僅新增空配方表並延伸扣料函式，不回填、不自動啟用任何商品。完成受控發布後，另以使用者授權的交易寫入家有三寶三筆15g配方，再啟用店家叫貨。初始三種各100g保持不動。

回復：先停用組合叫貨並將組合恢復草稿，停止新組合出貨；既有帳冊及取消回補保留。不得刪除已出貨帳冊。需要恢復舊函式時使用經審查的 forward migration，不刪庫存或強制回滾歷史資料。
