# 換罐共用單品庫存

換罐商品只保存售價、規格及來源單品，不建立自己的 HQ 庫存。一般商品維持原扣帳流程。

## 驗收

- 建單及包裝不扣庫存；寄出按換罐規格重量乘數量扣 WH-MAIN 來源單品。
- 同筆出貨同時含一般品、換罐品時共用同一來源餘額。
- 寄出／送達重送不重扣；取消／退貨按原始帳冊回補一次。
- 修改來源對應後取消歷史出貨，仍回補原扣帳單品。
- 無對應、來源停用、錯誤單位、自指或鏈狀對應不得出貨。
- 換罐自身不新增 InventoryBalance；庫存工作台不列換罐 SKU。
- 訂單選品顯示來源單品克數；出貨提醒與稽核查來源扣帳。
- 商店 POS 實際罐數仍須記錄；不更動商店庫存表。

## 發布與資料

migration_plan=standard。migration 僅新增可空白的來源欄位、外鍵、索引及驗證／扣帳函式，不回填資料。

另行核准的有限對應設定（僅 JAR_EXCHANGE → STANDARD，依唯一 SKU，不按名稱模糊配對）：

| 換罐 SKU | 來源 SKU |
|---|---|
| RF-beef-20、FUR-0035 | FUR-0022 |
| RF-anchovy-15、FUR-0038 | FUR-0023 |
| RF-crystal-fish-10、FUR-0039 | FUR-0028 |
| RF-veggie-25、FUR-0040 | FUR-0003 |
| RF-chicken-20 | FUR-0024 |
| RF-pig-ear-30、FUR-0037 | FUR-0011 |
| RF-duck-throat-15、FUR-0041 | FUR-0008 |

不回填或改寫歷史負庫存、不補扣歷史出貨。來源未設定的商品無法出貨，須在商品頁選擇庫存來源。

回復：停止換罐出貨並還原前版扣帳函式；保留新欄位與全部帳冊。新出貨已記來源單品身份，取消回補仍以原帳冊為準，不可刪除或改寫帳冊。回復舊版前須人工核對新出貨，避免重新使用錯誤的獨立換罐庫存。
