# LINE 換罐對話機制交付清單

日期：2026-11-20  
狀態：進行中（完成所有驗收項目後才可關閉）

## 目標

讓 LINE Bot、LIFF、HQ 與 POS 使用同一套換罐資料與狀態：

- LINE Bot：回答、導覽與顯示結果
- LIFF：開戶、預購、付款與需要輸入的操作
- HQ：會員、規則、商品、訂單、點數與對帳的唯一管理來源
- POS：店員現場驗罐、交付與完成紀錄

## 不在本次修改範圍

- 不重建會員資料
- 不改 SKU、價格、庫存或歷史訂單
- 不建立第二套點數、付款或對帳帳本
- 不讓 Shopify 成為換罐會員與點數的主資料來源

## 驗收情境

1. 未開戶：換罐計畫 → 先看介紹 → 幫毛孩開戶 → LIFF → 回 LINE。
2. 已開戶：換罐計畫 → 我要換罐 → 預購／付款 → HQ 建單。
3. 店員：POS 查到同一張訂單 → 驗空罐 → 指派新罐 → 完成交付。
4. 會員：LINE 查到相同點數、序號與換罐紀錄。
5. HQ：可追蹤會員、店家、付款、交付與稽核紀錄。
