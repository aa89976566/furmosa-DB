# HQ 任務式介面規則

## 核心原則

- 一個畫面只要求使用者做一件事。
- 每一步只有一個主要按鈕；返回與取消使用次要樣式。
- 先顯示必要欄位，進階設定留到建立後。
- 系統用台灣工作語境說明下一步，不顯示資料表名稱、狀態碼或工程術語。
- Duolingo 的參考只用在清楚進度與逐步引導；不使用卡通語氣、獎勵動畫或遊戲化文案。

## 視覺

- 主色為暖白、黑與中性灰。
- 主要容器使用 2px 深色邊框、圓角與單一硬陰影。
- 主要操作為黑底白字；未選取項目為白底黑字。
- 手機優先，點擊區至少 44px；重要操作不可只靠圖示。
- 錯誤訊息直接說明如何修正，不使用「invalid」「error code」等文字。

## 任務流程

- 頁首只顯示任務名稱與進度，例如 `2 / 4`。
- 不同任務不可同時攤開在同一頁。
- 完成畫面只提供「完成」與下一個必要動作。
- 清單先顯示可辨識資訊：店名、編號、縣市或電話；敏感資訊按需要揭露。

## 新增店家套用

1. 搜尋既有店家。
2. 選擇合作方式。
3. 填寫店家資料（新店才出現）。
4. 確認並進入 POS 設定。
